Hướng dẫn tạo Power Automate Flow

Flow 1: Nhận kết quả kiểm tra
Vào make.powerautomate.com → Create → Instant cloud flow
Chọn trigger: "When an HTTP request is received"
Thêm action: "SharePoint – Create item" → chọn Site + List RoomCheckResults
Map các field: Room, Inspector, CheckDate, Status, PassCount, FailCount, GeneralNote, ResultsJSON...
Thêm action (nếu có ảnh): "SharePoint – Create file" → lưu vào Document Library
Save Flow → copy HTTP POST URL → dán vào mục Webhook URL trong Setup
Flow 2: Trả về cấu hình (phòng + checklist)
Tạo Flow mới, trigger "When an HTTP request is received"
Thêm action: "SharePoint – Get items" từ List RoomCheckConfig
Thêm action: "Response" → trả về JSON với body: @{outputs('Get_items')?['body']}
Copy URL → dán vào Config Webhook URL trong Setup
💡 Không có Flow 2? Không sao — cấu hình phòng và checklist vẫn lưu được local và chỉnh trong tab Quản lý này.
